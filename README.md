# EduSpace — المرحلتان 2 و3 (الكورسات + إدارة المحتوى + الامتحانات)

زيادة على المرحلة التانية، المرة دي كمان: شاشات إدارة الكورسات من جوه التطبيق للأدمن (إنشاء وتعديل ونشر وحذف الكورسات، أقسام ودروس بأنواعها، إعادة ترتيب) من غير أي SQL، وأساس الامتحانات: بنك أسئلة وامتحانات مؤقتة بعدد محاولات، تصحيح تلقائي للاختياري والصح/خطأ ومتعدد الإجابات وأكمل الفراغ، والمقالي بيتخزن للمراجعة اليدوية، وشاشة نتيجة بنجاح/رسوب.

## قاعدة البيانات: الهجرات المطلوبة بالترتيب

1. `supabase/migrations/0001_init.sql`
2. `supabase/migrations/0002_courses.sql`
3. `supabase/migrations/0003_exams.sql`

## إضافة محتوى للتجربة

- الكورسات: من جوه التطبيق — اعمل حسابك أدمن (أضف دور admin لحسابك في جدول user_roles من Table Editor، role_id بتاع admin من جدول roles) وبعدين من تبويب «حسابي» هتلاقي «إدارة الكورسات».
- الامتحانات: إنشاء الامتحانات والأسئلة لسه من Table Editor في المرحلة دي (شاشاتها للأدمن في مرحلة لاحقة): أضف exam بحالة published، وبعدين questions + question_options (علّم is_correct على الإجابات الصح)، واربطهم في exam_questions.

المرحلة دي بتضيف نظام الكورسات على أساس المرحلة الأولى: كتالوج الكورسات المنشورة مع بحث، صفحة كورس فيها الوصف والمدرس والمستوى والسعر، أقسام (وحدات) ودروس مرتبة، اشتراك ذاتي في الكورسات المجانية، شاشة درس حسب نوعه (فيديو باستكمال من آخر نقطة، نص، ملف PDF/مستند، رابط، صوت)، تتبع تقدم لكل درس على الخادم، ونسبة إكمال لكل كورس، وبطاقة «استكمل التعلم» في الصفحة الرئيسية بترجعك لآخر درس وقفت عنده.

## تحديثات التصميم وتأكيد البريد (مع المرحلة دي)

- شاشة بداية (Splash) متحركة بلوجو المنصة، حركات دخول للبطاقات والقوائم، وثيم محسّن بعمق وظلال وحواف مدورة.
- روابط تأكيد البريد واستعادة كلمة المرور بتفتح التطبيق مباشرة عبر الرابط `eduspace://login-callback`. في Supabase من Authentication ثم URL Configuration لازم: Site URL = `eduspace://login-callback` وإضافة نفس الرابط في Redirect URLs.
- اتصلحت أزرار شاشة «راجع بريدك» (إعادة الإرسال مع إشعار وانتظار 30 ثانية، ورجوع لتسجيل الدخول).

## قاعدة البيانات في المرحلة دي

نفّذ `supabase/migrations/0002_courses.sql` في SQL Editor بعد `0001_init.sql`. ده بيعمل جداول: courses, course_translations, course_sections, lessons, lesson_translations, enrollments, lesson_progress، وعرض course_progress_summary، مع سياسات RLS: الطالب يشوف الكورسات المنشورة، ويشترك بنفسه في المجاني بس، والدروس تتاح للمشتركين أو لدروس المعاينة المجانية، والتقدم ملك الطالب وحده. إنشاء وتعديل الكورسات والدروس من لوحة الأدمن في مرحلة لاحقة؛ للتجربة دلوقتي ممكن تدخل بيانات من Table Editor في Supabase (كورس status = published، قسم، ودروس).

## صراحة مهمة قبل ما تبدأ

أنا كتبت الكود كله وراجعته ملف ملف، لكن **مفيش عندي Flutter SDK في بيئة العمل بتاعتي**، فمقدرتش أعمل `flutter analyze` ولا أشغّل التطبيق بنفسي. يعني:
- اللي اتعمل: مراجعة يدوية للكود والبنية وملف SQL.
- اللي ما اتعملش: بناء ولا تشغيل ولا اختبار على جهاز حقيقي.
لو طلعلك أي خطأ في التشغيل، ابعتلي نص الخطأ أو صورة شاشة وهصلحه.

## اللي هتحتاجه

1. كمبيوتر عليه [Flutter SDK](https://docs.flutter.dev/get-started/install) (آخر نسخة مستقرة).
2. حساب مجاني على [Supabase](https://supabase.com).
3. موبايل أندرويد أو أيفون بكابل USB، أو محاكي.
4. **متبعتش أي مفاتيح في الشات أبداً.** المفاتيح مكانها جهازك بس.

## خطوات التشغيل خطوة بخطوة

### 1) جهز Flutter
- نزّل Flutter من الموقع الرسمي واتبع التثبيت لنظامك.
- تأكد إنه شغال: `flutter doctor` — لازم يطلع بدون أخطاء حمراء في الأساسيات.

### 2) اعمل مشروع Supabase
- من لوحة Supabase اعمل مشروع جديد (اختار كلمة مرور قوية لقاعدة البيانات واحفظها عندك).
- من Settings ثم API هتلاقي حاجتين: `Project URL` و `anon public key`. خدهم عندك في ملف على جهازك.

### 3) شغّل قاعدة البيانات
- افتح SQL Editor في Supabase.
- نفّذ `supabase/migrations/0001_init.sql` الأول (انسخه ونفّذه Run).
- وبعدين عندك خيارين: يا تنفّذ `supabase/all_0002_to_latest.sql` مرة واحدة (فيه كل المايجريشنز من 0002 لحد 0007، وآمن لإعادة التشغيل)، يا تنفّذ ملفات `supabase/migrations/` من 0002 لحد 0009 واحد واحد بالترتيب.
- عشان تبقى أدمن: افتح `supabase/grant_admin.sql`، حط بريدك مكان البريد المكتوب، ونفّذه.
- ده هيعمل الجداول والصلاحيات (RLS) وإنشاء الملف الشخصي تلقائياً عند التسجيل، وهيضيف لغتين (ar, en) والأدوار الأساسية والكورسات والامتحانات والإشعارات والشهادات.
- من Authentication ثم Providers تأكد إن Email شغال. للتجربة السريعة ممكن تقفل "Confirm email"، بس للإطلاق سيبها شغالة (الشاشة جاهزة لها).

### 4) شغّل التطبيق
- افتح طرفية في فولدر المشروع `eduspace_app` ونفّذ:
```
flutter pub get
flutter run --dart-define=SUPABASE_URL=الرابط_بتاعك --dart-define=SUPABASE_ANON_KEY=المفتاح_بتاعك
```
- أول تشغيل هيسألك تختار اللغة، وبعدين تقدر تعمل حساب وتدخل.

### 5) جرب على موبايلك
- وصّل الموبايل بكابل وفعّل وضع المطور (Developer Mode) وتصحيح USB.
- `flutter devices` يوريك الأجهزة المتاحة، وبعدين نفس أمر التشغيل اللي فوق.

## تغطية وثيقة الرؤية — إيه اللي اتعمل وإيه اللي فاضل

| بند الوثيقة | الحالة في المرحلة دي |
|---|---|
| 4. تعدد اللغات | اتعمل أساسه: نظام ترجمة مركزي + عربي RTL وإنجليزي LTR + اختيار اللغة من الإعدادات وجداول اللغات والترجمات. فاضل: اختيار اللغة في أول تشغيل كشاشة منفصلة، ولغات إضافية |
| 5. الوضع النهاري والليلي | اتعمل: نهاري/ليلي/اتباع النظام مع حفظ الاختيار. فاضل: فحص بصري شامل لكل شاشة في الوضعين |
| 6. الأدوار والصلاحيات | اتعمل أساسه في قاعدة البيانات: الأدوار والصلاحيات وRLS ودالة فحص الأدمن وسجل النشاط. فاضل: شاشات إدارة الأدمن (ل5–ل7) |
| 7. حسابات الطلاب | اتعمل: تسجيل بالبريد + تحقق + استعادة كلمة مرور + حالات الحساب (قيد مراجعة/مرفوض/موقوف) + حماية تغيير الحالة. فاضل: تسجيل Google/Apple |
| 8. الملف الشخصي | اتعمل أساسه: عرض وتعديل الاسم والهاتف + كل الحقول في قاعدة البيانات. فاضل: باقي الحقول الاختيارية في الواجهة وصورة شخصية |
| 9. الصفحة الرئيسية والتنقل | اتعمل: شريط سفلي بأربع شاشات + بطاقة «استكمل التعلم» (آخر درس) + كورساتي مع نسبة التقدم + بنر الإعلانات + أيقونة إشعارات بعدّاد غير المقروء. فاضل: الأقسام الديناميكية اللي يتحكم فيها الأدمن (بنرات، لايفات قادمة) |
| 10. نظام الكورسات | اتعمل أساسه للطالب: كتالوج + بحث + صفحة كورس + أقسام ودروس + اشتراك مجاني + حالات كورس في قاعدة البيانات + ترجمات كورس ودرس. فاضل: إنشاء وتعديل الكورسات من لوحة الأدمن، مفضلة وتقييمات ومراجعات، فلاتر حسب المجال/المستوى، إتاحة الدروس بالتتابع/التاريخ (موجودة في قاعدة البيانات لكن غير مطبقة في الواجهة) |
| 12. الفيديو والمحتوى | اتعمل جزئياً: مشغل فيديو يستكمل من آخر نقطة ويحفظ التقدم على الخادم ويكتمل تلقائياً عند 90%. فاضل: تحكم في السرعة والجودة، Subtitles، روابط موقعة للمحتوى الخاص، منع التنزيل |
| 14. الامتحانات وبنك الأسئلة | اتعمل أساسه للطالب: جداول بنك الأسئلة والامتحانات والمحاولات والإجابات + امتحان مؤقت + تصحيح آلي (اختياري/صح-خطأ/متعدد/أكمل الفراغ) + نتيجة فورية + عدد محاولات وإتاحة بتاريخ في قاعدة البيانات. فاضل: شاشات إنشاء الامتحانات للأدمن، خلط الأسئلة من البنك عشوائيًا، تصحيح المقالي، استيراد Excel/CSV، إظهار الإجابات الصحيحة بعد التصحيح |
| 21. لوحة الإدارة | اتعمل داخل التطبيق: لوحة إدارة موحدة (Dashboard بأعداد الطلاب والكورسات والاشتراكات والشهادات) + إدارة المستخدمين (بحث وفلترة وقبول/رفض/إيقاف مع سبب) + إدارة الكورسات كاملة + إدارة الامتحانات وبنك الأسئلة + الاشتراكات (عرض ومنح وسحب وصول) + الشهادات (بحث وإلغاء بسبب) + الإعلانات والبث. فاضل: لوحة الويب، المدفوعات، اللايفات، المكتبة، التكليفات، الدعم، التقارير، الإعدادات العامة |
| 17. الشهادات | اتعمل: إصدار تلقائي عند إتمام الكورس 100% (RLS بيتحقق من إكمال كل الدروس) + رقم شهادة فريد + شاشة «شهاداتي» + تصميم شهادة يتشارك كصورة + تصدير PDF للطباعة مع QR + رابط تحقق عام (دالة `verify_certificate` في قاعدة البيانات ترجع حالة الشهادة لأي حد معاه الرقم). فاضل: قوالب شهادات متعددة، صفحة تحقق ويب منسقة، إدارة/إلغاء من لوحة الأدمن (الحالة موجودة في القاعدة) |
| 18. الإشعارات والإعلانات | اتعمل: قائمة إشعارات داخلية + عدّاد غير المقروء على الرئيسية + بنر إعلانات + الأدمن ينشئ إعلانات من التطبيق + إرسال إشعار لكل المستخدمين (دالة server-side بتحترم تفضيلات كل مستخدم) + شاشة تفضيلات الإشعارات بالفئات في الإعدادات. فاضل: إشعارات Push (FCM)، جدولة إشعار مستقبلي، ترجمة الإشعارات |
| 15. التكليفات | اتعمل أساسه: الأدمن ينشئ تكليفات لكل كورس (وصف، مرفق، موعد نهائي، درجة عظمى، قبول التأخير) + الطالب يسلّم نصًا أو رابطًا ويعدّل تسليمه قبل التقييم + حالة «متأخر» تلقائية + الأدمن يقيّم بدرجة وملاحظات ويوصل إشعار للطالب. فاضل: رفع ملفات (محتاج Storage bucket)، عدد محاولات متعدد، سياسات خصم التأخير |
| 20. المفضلة والتقييمات | اتعمل أساسه: مفضلة لكل طالب (قلب على الكارت وصفحة الكورس + شاشة المفضلة في الحساب) + تقييم بالنجوم ومراجعة (للمشتركين بس، RLS بتفرضه) مع متوسط التقييم على الكورس. فاضل: شارات الإنجاز، الإشراف على المراجعات من لوحة الأدمن |
| 11, 13, 16, 19, 22 (المدفوعات، اللايفات، المكتبة، الدعم، App Builder) | لسه — جداولها جاهزة في المخطط وتتضاف مرحلة مرحلة |
| 23. Multi-Tenant | مؤجل بقرارك — التصميم متجهز لإضافته |
| 26. قاعدة البيانات | اتنفذ منها لحد دلوقتي: profiles, roles, permissions, user_roles, role_permissions, admin_activity_logs, languages, translation_keys, translations (مرحلة 1) + courses, course_translations, course_sections, lessons, lesson_translations, enrollments, lesson_progress, course_progress_summary (مرحلة 2) + question_banks, questions, question_options, exams, exam_questions, exam_attempts, answers (مرحلة 3) + notifications, announcements, certificates (مرحلة 4) + دالة التحقق العامة من الشهادات verify_certificate (مرحلة 5) + notification_preferences ودالة البث admin_broadcast_notification (مرحلة 6). الباقي يتضاف مع مراحل المميزات |

## هيكل المشروع
```
eduspace_app/
  lib/
    main.dart                 نقطة البداية
    app.dart                  إعداد التطبيق والثيم واللغة
    core/                     الإعدادات والترجمة والثيم وحالة التطبيق
    features/
      auth/                   الدخول والتسجيل والتحقق واستعادة كلمة المرور وحالة الحساب
      home/                   هيكل التنقل السفلي + الرئيسية
      courses/                الكتالوج وصفحة الكورس والدروس ومشغل الفيديو
      exams/                  قائمة الامتحانات وشاشة الامتحان المؤقت
      admin/                  إدارة الكورسات (أقسام ودروس) من التطبيق
      notifications/          الإشعارات الداخلية والإعلانات
      certificates/           شهاداتي وعرض ومشاركة الشهادة
      profile/                الملف الشخصي وتعديله
      settings/               اللغة والمظهر
  supabase/migrations/        ملف SQL لقاعدة البيانات
```
