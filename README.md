# EduSpace — المرحلة الأولى (الأساس)

دي أول مرحلة شغالة من تطبيق EduSpace: تسجيل دخول وإنشاء حساب وتحقق بالبريد واستعادة كلمة مرور، ملف شخصي، لغتين (عربي RTL وإنجليزي LTR) بنظام ترجمة مركزي، وضع نهاري وليلي واتباع النظام، وهيكل التنقل السفلي (الرئيسية، الكورسات، الامتحانات، حسابي)، وقاعدة بيانات Supabase فيها الجداول والصلاحيات الخاصة بالمرحلة دي.

## صراحة مهمة قبل ما تبدأ

أنا كتبت الكود كله وراجعته ملف ملف، لكن **مفيش عندي Flutter SDK في بيئة العمل بتاعتي**، فمقدرتش أعمل `flutter analyze` ولا أشغّل التطبيق بنفسي. يعني:
- اللي اتعمل: مراجعة يدوية للكود والبنية وملف SQL.
- اللي ما اتعملش: بناء ولا تشغيل ولا اختبار على جهاز حقيقي.
لو طلعلك أي خطأ في التشغيل، ابعتلي نص الخطأ أو صورة شاشة وهصلحه.

## اللي هتحتاجه

1. كمبيوتر عليه [Flutter SDK](https://docs.flutter.dev/get-started/install) (آخر نسخة مستقرة).
2. حساب مجاني على [Supabase](https://supabase.com).
3. موبايل أندرويد أو أيفون بكابل USB، أو محاكي.
4. **متبعتش أي مفاتيح في الشات أبداً.** المفاتيح مكانها جهازك بس.

## خطوات التشغيل خطوة بخطوة

### 1) جهز Flutter
- نزّل Flutter من الموقع الرسمي واتبع التثبيت لنظامك.
- تأكد إنه شغال: `flutter doctor` — لازم يطلع بدون أخطاء حمراء في الأساسيات.

### 2) اعمل مشروع Supabase
- من لوحة Supabase اعمل مشروع جديد (اختار كلمة مرور قوية لقاعدة البيانات واحفظها عندك).
- من Settings ثم API هتلاقي حاجتين: `Project URL` و `anon public key`. خدهم عندك في ملف على جهازك.

### 3) شغّل قاعدة البيانات
- افتح SQL Editor في Supabase.
- انسخ محتوى ملف `supabase/migrations/0001_init.sql` كله ونفّذه (Run).
- ده هيعمل الجداول والصلاحيات (RLS) وإنشاء الملف الشخصي تلقائياً عند التسجيل، وهيضيف لغتين (ar, en) والأدوار الأساسية.
- من Authentication ثم Providers تأكد إن Email شغال. للتجربة السريعة ممكن تقفل "Confirm email"، بس للإطلاق سيبها شغالة (الشاشة جاهزة لها).

### 4) شغّل التطبيق
- افتح طرفية في فولدر المشروع `eduspace_app` ونفّذ:
```
flutter pub get
flutter run --dart-define=SUPABASE_URL=الرابط_بتاعك --dart-define=SUPABASE_ANON_KEY=المفتاح_بتاعك
```
- أول تشغيل هيسألك تختار اللغة، وبعدين تقدر تعمل حساب وتدخل.

### 5) جرب على موبايلك
- وصّل الموبايل بكابل وفعّل وضع المطور (Developer Mode) وتصحيح USB.
- `flutter devices` يوريك الأجهزة المتاحة، وبعدين نفس أمر التشغيل اللي فوق.

## تغطية وثيقة الرؤية — إيه اللي اتعمل وإيه اللي فاضل

| بند الوثيقة | الحالة في المرحلة دي |
|---|---|
| 4. تعدد اللغات | اتعمل أساسه: نظام ترجمة مركزي + عربي RTL وإنجليزي LTR + اختيار اللغة من الإعدادات وجداول اللغات والترجمات. فاضل: اختيار اللغة في أول تشغيل كشاشة منفصلة، ولغات إضافية |
| 5. الوضع النهاري والليلي | اتعمل: نهاري/ليلي/اتباع النظام مع حفظ الاختيار. فاضل: فحص بصري شامل لكل شاشة في الوضعين |
| 6. الأدوار والصلاحيات | اتعمل أساسه في قاعدة البيانات: الأدوار والصلاحيات وRLS ودالة فحص الأدمن وسجل النشاط. فاضل: شاشات إدارة الأدمن (ل5–ل7) |
| 7. حسابات الطلاب | اتعمل: تسجيل بالبريد + تحقق + استعادة كلمة مرور + حالات الحساب (قيد مراجعة/مرفوض/موقوف) + حماية تغيير الحالة. فاضل: تسجيل Google/Apple |
| 8. الملف الشخصي | اتعمل أساسه: عرض وتعديل الاسم والهاتف + كل الحقول في قاعدة البيانات. فاضل: باقي الحقول الاختيارية في الواجهة وصورة شخصية |
| 9. الصفحة الرئيسية والتنقل | اتعمل الهيكل: شريط سفلي بأربع شاشات. فاضل: محتوى الرئيسية الديناميكي وأقسامها |
| 10–22 (الكورسات، المدفوعات، الفيديو، اللايفات، الامتحانات، التكليفات، المكتبة، الشهادات، الإشعارات، الدعم، المفضلة، لوحة الإدارة) | لسه — جداولها جاهزة في المخطط وتتضاف مرحلة مرحلة |
| 23. Multi-Tenant | مؤجل بقرارك — التصميم متجهز لإضافته |
| 26. قاعدة البيانات | اتنفذ منها في المرحلة دي: profiles, roles, permissions, user_roles, role_permissions, admin_activity_logs, languages, translation_keys, translations. الباقي يتضاف مع مراحل المميزات |

## هيكل المشروع
```
eduspace_app/
  lib/
    main.dart                 نقطة البداية
    app.dart                  إعداد التطبيق والثيم واللغة
    core/                     الإعدادات والترجمة والثيم وحالة التطبيق
    features/
      auth/                   الدخول والتسجيل والتحقق واستعادة كلمة المرور وحالة الحساب
      home/                   هيكل التنقل السفلي والشاشات المؤقتة
      profile/                الملف الشخصي وتعديله
      settings/               اللغة والمظهر
  supabase/migrations/        ملف SQL لقاعدة البيانات
```

- المفاتيح والكلمات السرية متتبعتش أبداً.
